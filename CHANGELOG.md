# Changelog

## 1.0.0 — 2026-11-04

First accepted release of PDF Desk. User acceptance testing of a real PDF workflow is complete.

- Local, offline browser app with the Focus thumbnail-sidebar design and a large page preview.
- Merge PDFs; import JPEG/PNG images; insert A4, Letter or matching-size blank/image pages.
- Select, reorder, move, rotate, duplicate and delete pages, with undo/redo.
- Preview navigation, zoom, fit-to-page and fit-to-width.
- Save all pages or selected pages as a new PDF, preserving source files.
- 100 MB combined input limit, per-file import errors and unsaved-change warnings.
- Windows launchers, shortcut creation and stop script.
- Bundled PDF.js, pdf-lib and Lucide assets with upstream licence notices.
- 28 automated tests, verified Edge/Chrome workflows, independent PDF validation, synthetic sample files and documented large-file checks.

Known boundaries: regular unencrypted PDFs only; no text/content editing, session recovery, or guarantee of preservation for forms, bookmarks, signatures and specialist PDF features. See the README for full details.
